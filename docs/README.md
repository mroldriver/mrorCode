## 维护约定

- **project-plan-atomcode.md** 描述「现在是什么样」，架构/选型/状态变化时同步更新。
- **roadmap.md** 是已完结里程碑的历史存档，保留原文与实测数据；新里程碑追加新章节，不回改历史。
- 文档为中文（与既有注释、设计文档保持一致）；相对链接必须可跳转。
- 项目结构、构建/测试命令、架构边界或开发约定变化时，同步更新根 [AGENTS.md](../AGENTS.md)。
